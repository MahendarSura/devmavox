ANSWER: A merge conflict occurs when Git cannot automatically combine changes from different branches or commits. This commonly happens when two developers modify the same lines of a file in different ways, or when one change deletes a file that another change modifies.

For example, two developers may update the same application configuration value differently. The team must understand the intended configuration before selecting or combining the changes. Simply removing conflict markers without checking the logic can introduce defects.
