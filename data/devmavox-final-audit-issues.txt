QUESTION: What is a panel in Grafana?
ANSWER: A panel is an individual visualization or information component inside a dashboard. Each panel normally uses a query against a data source. One panel may display CPU utilization, another memory consumption, and another application errors.

QUESTION: What is a Grafana data source?
ANSWER: A data source is an external system from which Grafana retrieves information. Examples include Prometheus, Loki, Elasticsearch, InfluxDB, and supported SQL databases. Prometheus can provide metrics while Loki provides logs.

QUESTION: What is the difference between Grafana and Prometheus?
ANSWER: Prometheus collects, stores, and queries time-series metrics. Grafana connects to data sources and visualizes their information. For example, Prometheus collects Linux CPU usage, while Grafana displays that information as a graph.

ANSWER: The clean lifecycle removes files generated by previous builds, normally from the project's target directory. It helps avoid accidentally using stale compiled classes or packaged outputs. It is commonly run before a fresh CI build.

QUESTION: What does mvn package do?
ANSWER: The package phase creates the distributable artifact, such as a JAR or WAR, according to the project's packaging configuration. Earlier required lifecycle phases are executed first. The generated artifact is commonly found in the target directory.
